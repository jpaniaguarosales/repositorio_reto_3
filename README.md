# Mi espacio web

Este proyecto es una landing sencilla creada para practicar desarrollo web en segundo curso de DAW. Presenta el propósito del proyecto y algunos de los temas que estoy aprendiendo.

Para ver la página, abre la carpeta del proyecto en el Explorador de archivos y haz doble clic en `index.html`. El archivo se abrirá en el navegador predeterminado. No hace falta instalar dependencias ni iniciar un servidor. En la landing encontrarás una presentación del proyecto y una sección sobre lo que estoy aprendiendo.

## Archivos

- `index.html`: contiene el contenido y la estructura de la landing.
- `README.md`: explica el proyecto y cómo abrirlo.
